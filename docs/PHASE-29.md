# Phase 29: MACRO listings, traceback, and debugger records

## Goal

Give govax's `MACRO` command the outputs real MACRO has that Phase 27 left
out:

- **Listing files** (`/LIST`): the source beside the generated bytes, the
  psect synopsis, and the symbol table.
- **Traceback records** (TBT), which real MACRO writes by default
  (`.ENABLE TRACEBACK`), so that a failing image gives a symbolic
  traceback.
- **Debugger records** (DBG, for `/DEBUG` and `.ENABLE DEBUG`).

Split out of Phase 27's "later sub-phases" (docs/PHASE-27.md, subtask 12).

**Status: planned, not started.**

## What Phase 27 leaves in place

- `internal/obj` already reads, writes, dumps, and checks DBG and TBT
  records: they carry the same commands as TIR records.
- `testdata/mar/vax/` holds real MACRO's listing (`.lis`) and full object
  (traceback included) for each of the twelve fixtures. They're the
  comparison target: `TestFixtureLadderObjects` currently leaves traceback
  records out (`withoutTraceback`), and this phase should remove that.
- `.SUBTITLE`/`.SBTTL` are accepted and ignored.
- `.ENABLE TRACEBACK`/`DEBUG` are recorded and have no effect.

## What Phase 28 leaves in place

- Macros and repeat blocks expand through a stack of sources
  (`internal/asm/source.go`), each frame knowing its macro or block and
  line, which a listing needs to show expansions (`.SHOW
  EXPANSIONS`/`BINARY`, real MACRO's `.NOSHOW` default for macro
  expansions).
- `.LIST`/`.NLIST`, `.SHOW`/`.NOSHOW`, `.CROSS`/`.NOCROSS`, and `.PAGE` are
  accepted and ignored (`internal/asm/directive.go`).
- `testdata/mar/macros/vax/` adds nine more real listings and full
  objects, with macro calls in them. `TestMacroFixtureObjects` compares
  through the same `requireSameObject`, which leaves traceback records
  out.

## Scope

- `/LIST[=file]` on the `MACRO` command, written through
  `rms.Session.CreateRecordFile` with the text record kind, so it works on
  the host or a volume.
- Listing control directives: `.LIST`/`.NLIST`, `.SHOW`/`.NOSHOW`,
  `.PAGE`, `.SBTTL`, and the MACRO manual's other listing controls.
- TBT records by default, matching the fixtures' real objects.
- `/DEBUG` and the DBG records it adds.

## References

- *VAX MACRO and Instruction Set Reference Manual*: the listing
  directives in chapter 6, and the listing format.
- `vmssrc_archive/v73/debug/lis/dstrecrds.sdl` (and `.lis`): the debug
  symbol table (DST) records that TBT and DBG records carry.
- `vmssrc_archive/v73/trace/lis/`: the traceback facility, which reads
  TBT data at run time.
- The real listings and objects in `testdata/mar/vax/`.

## Open questions

- **Listing fidelity.** How closely must a listing match real MACRO's
  layout (column positions, page headers with dates and page numbers)?
- **Does govax use traceback?** Does govax's own `RUN` (Phase 13) or
  condition handling (Phase 26) need to use the traceback data, or is
  writing it for a real VMS linker enough?
